Welcome to Possum!

Possum is a... well, it could be a lot of things. It's an event player... based on a system that allows plug-ins to be written for a schedulable (is that word?) purpose. Today, right now, Possum is a Digital Audio Workstation.

You can create music with it using multiple waveform synths, noise, and samples, then apply spline-based envelopes to them - globally or per-track.

Someday, Possum could run synchronized laser shows, or whatever. It's... a dream. Not sleeping, just playing Possum.
